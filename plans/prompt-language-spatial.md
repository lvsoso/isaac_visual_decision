## 信息与翻译边界

- 语言对照：只翻译自然语言字符串，协议键名、动作 ID、previous_action / previous_result、工具 / 连杆 ID、数字、图片与候选顺序原样保留；并非重写官方系统提示或聊天模板。
- 颜色对照：只改变 task 和 instructions 中的目标指认句，不改变动作条件、图片、数值或其他状态。
- 空间表达对照：改写 state 中的工具 / 放置目标、手指连杆坐标和相机描述；米变厘米（小数 1 位，单量舍入误差最多 0.05 cm），角度 1 位。目标相对工具的水平距离、带符号高度差仍来自相同配置 / 实测关节模型 FK。保留配置目标、工具目标和实测工具的近似绝对位置；相机方向由原位置、朝向点和角度描述。不把世界 +X / +Y 称为画面左 / 右。
- 这一空间因素包含单位、精度、文字格式和冗余几何表达简化的整包变化，不能单独归因于“中文”或某一种四舍五入规则。它不是信息逐位无损的转换。
- 不写“已对齐”“已抓住”“应 lower / release”等标签，不加入固定动作顺序、阶段编号、参考动作、阈值判断、方块位置真值、接触 / 持有真值或隐藏状态。工具点不是方块中心；位置接近目标不证明抓牢。
- 英文 neutral_raw 请求必须逐字节重建并匹配原 `26_static_factorial_replay` 的 A0B1C1 / A1B1C1 请求；在新服务批次中重跑作为稳定性对照，不直接借用历史概率充当新实验。
