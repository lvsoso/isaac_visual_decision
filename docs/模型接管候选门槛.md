# 在线shadow达标后才列入模型接管候选

按用户要求，**未达到7/7的组合不进入模型控制环节**。这是一项实验入选规则，不是自主抓放成功率或安全认证。

## 达标条件

同一个明确的模型／输入模态／语言／提示／目标条件，必须同时满足：

1. 在真实Isaac运行中，从每个当前物理状态实时调用模型，不是重放已保存请求。
2. 固定执行器完整完成七个阶段和自动retract，最终物理评分通过。
3. 七次真实调用都有效，无API错误、重试、阶段超时或等待期间物理状态漂移。
4. 模型官方建议与七个参考动作 **7/7一致**；不归一化改choice、不补答案、不用动作掩码制造一致。
5. 原始请求／响应、模型版本、候选与提示、物理／调用记录均保留，能够独立审计。

若作为蓝黄两色组合入选，两色都须达标。只有某一色达标，不代表另一色或整个组合通过。

Jev在线入口在summary中记录 `control_gate`；**eligible只是候选资格，不会自动启动模型控制**。本轮不调用既有 `--mode visual`，也不会因为固定执行器抓放成功就把模型建议视为成功。

## 新Jev在线影子入口

```bash
OMNI_KIT_ALLOW_ROOT=1 LD_LIBRARY_PATH="" "$ISAAC_ROOT/python.sh" \
  "$LAB/run_jev_shadow.py" --isaac-root "$ISAAC_ROOT" --headless \
  --goal-color blue --run-dir "$LAB/runs/新的蓝色影子回合" \
  --worker-python /独立模型环境/bin/python --key-file /私密密钥文件
```

- 每回合最多七次Jev推理；必须使用新的输出目录。
- 单独模型Python子进程读取密钥并调用HTTPS；Isaac端不读取密钥、不安装模型或SDK依赖。
- 输入来自实时本体状态、配置目标与实测关节FK；PNG仅为审计，不送给Jev；物体位置和夹持真值不送模型。
- 等待API时暂停物理，前后快照一致才允许固定执行器执行下一阶段。
- 采用 `jev_sdk_basic_v1`，候选和原始数值保留；调用错误停止，合法的模型abort建议只记录，不改变固定序列。
- 提示沿用英文无图描述，仅将offline action suggestions改成online shadow action suggestions并预先冻结；新的当前测量值只能逐次在调用前归档，不谎称提前冻结。

后续受限仿真接管还要明确运行范围、动作许可、步数及超时／错误停止规则，并另获授权。未达标Jev只保留为对照；其他组合也必须通过自己的真实在线shadow，不凭离线7/7直接入选。
