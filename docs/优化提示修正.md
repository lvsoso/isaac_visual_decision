# 无图提示修正：先匹配输入，再重测

旧28批次无图输入仍要求“根据当前RGB图像”和“检查方块是否位于手指之间”，给模型提出了无法完成的要求。**撤回将旧2/7解释为合理无图能力、将2/7→7/7解释为公平视觉收益的结论。** 原输入、响应与历史HTML保留，用于复盘，不修改后冒充新推理。

## 修正后的提示

新版本为 `modality_aware_v1`，完整指令和八技能定义在 [visual_lab/modality_prompts.py](../visual_lab/modality_prompts.py)。无图提示的核心是：

> 本次没有提供图片或视频，只提供文字与本体状态。综合当前数值、上一动作、执行结果和全部技能含义，选择最合理的下一步技能。允许依据已有记录推断进展，但推断不是测量事实，上一动作不是强制序列。手指闭合、姿态收敛、工具接近目标均不能证明夹持；没有图片本身也不是必须abort的理由。

- **无图：** `images=[]`、`camera_views=[]`，去掉全部看图命令及需要图像才能履行的技能条件；不假定已抓住，不因未知自动认定丢失。
- **单图：**只声明实际提供的第一相机，保留该相机角度和原PNG；不声称还有第二视角。
- **双图：**沿用27 / 28批次有效双图提示，14份输入逐字节一致，作为重新推理的稳定性对照。
- 任务、手指与工具数值、配置目标、上一动作与结果保持原样；不增加方块真值、夹持标签、正确动作、序列或候选掩码，不更改官方模型、模板、温度或平局结果。

这是**提示修正整包**，新0 / 1 / 2图比较包含提示与相机说明适配，不再声称是纯图片因果效应。
