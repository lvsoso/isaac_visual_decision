## 能与不能解释什么

修正后仍观察到这版无图、单图、双图条件的明显差异，**但新比较包含图片与提示 / 相机说明适配，不是纯图片因果效应，也不能证明已找到最优纯文本提示**。仅说明当前明示无图的固定提示没有复现这条轨迹，不推广为模型纯文本推理普遍弱。

无图的abort是模型建议，不是已经执行的物理失败。模型没有输出原因，因此不能断言其停止是“缺乏夹持证据”或某一句话造成。文字提供工具与目标几何，但没有方块位置或实际夹持测量；轨迹上的建议与任务状态证明必须区分。记录可提供进展线索，却不能证明物体确实随夹爪运动。

双图7/7也不代表可稳健接管：lower概率蓝25.90%、黄25.96%，仅领先第二候选1.57 / 1.58个百分点。蓝release领先4.40个百分点。仍未验证模型自主抓放、扰动恢复或新场景泛化。
