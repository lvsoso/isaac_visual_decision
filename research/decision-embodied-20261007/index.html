01

不要把不同测试当成同一个问题

1
Jev 不看图，观测先被翻译为文字。

当前 Jev 1.13 是 text-only。六个具身项目中的 Jev 路径都将观测转为坐标、关系、接触、可见性或候选效果；Intern-Decision 则有真实图片编码路径。

2
状态选对，不等于闭环任务做成。

文本准确率、合成空间探针、单回合演示、物理任务成功率、API 吞吐是五类证据，分母和成功定义不同，不能直接互换。

3
动作候选里已经包含大量工程能力。

IK、预设抓取姿态、动态候选过滤、仿真分支和安全否决由程序提供。jev-libero 甚至先计算候选动作的反事实结果，再让模型选择。

4
“成功”可能没有验证完整操作。

jev-libero 的 soup 记录通过原始 LIBERO 判据时物体仍被夹住；EmbodiedJev 的两局终态通过包含失抓落盘；无人机 crossed_barrier 只表示跨第一道梁。

5
同一个 confidence 数值，也不是同一把尺。

Jev / Kev 的 Choice confidence 对均匀基线归一化；Intern 用 max(P)；SemIf 默认读出未校准；AnyJev L0 是无标签纠偏，不是监督概率校准。

6
最新代码不一定对应旧演示。

EmbodiedJev LIBERO v1 与 v2、RoboJEV 不同评测 campaign、AnyJev 旧 L1 与当前 L0/Tacit 都必须分版本。保存示例的 schema 也可能落后于 HEAD。

输入不是单一的“state”：先区分五层

DATA / 01原始图像

RGB 字节、像素与图像 token。Intern 支持；Jev 不支持。上传图像不等于已证明视觉控制能力。

DATA / 02视觉派生状态

RGB-D 前处理得到坐标、距离、标签、可见性。能力归属：感知代码与决策模型分开。

DATA / 03仿真特权状态

直接读对象真值坐标、理想接触、geom ID。可做决策隔离实验，但不是现实感知链。

DATA / 04反事实候选效果

仿真器先执行分支，回传碰撞、进展乃至成功标志。模型做筛选，预测来自仿真器。

DATA / 05监督与评分真值

label、targets、y、独立物理 evaluator。只进训练损失或离线评分，不能混入待测证据。

04

它们的测试思路，可以拆成五层

LEVEL 1 / CONTRACT

接口、约束与软件回归

验证 schema、合法候选、概率形状、取消、过期响应、快照恢复、传输失败和硬安全门。RoboJEV、jev-libero、EmbodiedJev 有 mock / 离线软件测试；官方 Jev SDK 的 live integration 主要断言返回字段和范围。它们证明软件契约，不证明语义判断正确或机器人完成任务。

LEVEL 2 / OFFLINE DECISIONS

冻结状态集与合成探针

给固定 state + question + candidates，独立标签评分，保存完整输出。Kev、SemIf、Intern 的文字套件和 RoboJev 的空间 / standing-order 探针属于此层。训练 label 与评测 y 必须剥离；按场景、题族、轨迹分组，而不只是按单行随机划分。

LEVEL 3 / CALIBRATION & SYSTEMS

概率、顺序、共享缓存与延迟

固定模型 / 提示 / 输入后测试 NLL、Brier、ECE、候选重排、原始与共享缓存一致性、风险-覆盖、网络 / 推理 / 排队时延。SemIf 的 direct-vs-generation 是系统实验，不是等质量证明；AnyJev L0 的停止证书保证与自身全轮答案一致，不保证正确。

LEVEL 4 / SIM CLOSED LOOP

模型真实接管后的独立回合

同初态、同动作菜单、同执行器和预算，执行模型选择，重新观测，用独立物理谓词评分。RoboJEV 的固定种子 + 独立规则策略是较清晰范例；jev-libero 额外享有分支预演，应单列设置。保存所有失败、无效响应、预算耗尽和复试历史。

LEVEL 5 / HARDWARE

真实感知、异步时序与硬安全

alee792/RoboJev 提供真机观察与事件驱动工程，但缺少完整公开运行日志和系统性成功率评测。必须记录标定、感知失败、快照年龄、力 / 温度 / 工作区限制。网络模型不能替代高频飞控、关节伺服或独立急停。

常见指标：分母与语义必须一起写

指标含义 / 常用计算这些项目中的陷阱
准确率 / agreementargmax 与参考标签一致数 / 预先确定的总数参考可能是人工标签、几何标签、参考模型众数或固定序列；它们不是同一“真值”。多字段一行不等于一个决策。
物理成功率满足独立终态谓词的回合 / 全部计划回合必须说明是否需要松爪、稳定支撑、撤离、零碰撞；不得把“到达容器”自动写成“完整放置”。
Brier常见多类形式 mean Σk(pk − yk)²，取值随定义 / 类别数而变已知分布 pilot 用期望 Brier，含不可约随机性；不能与一次采样标签的经验 Brier 或二类单项版本直接比。
ECE按 confidence 分箱，Σb nb/N × |accb − confb|分箱、confidence 定义、参考分布、拟合/测试是否同批都改变口径。温度缩放不改变 argmax。
风险-覆盖coverage = 被接受样本 / 全部样本；risk = 接受子集错误数 / 接受数评测集上找出的 coverage@5% 不是部署保证；阈值应在独立校准集确定，再评价 held-out 风险。
选项翻转重排后映回语义候选 ID，检查选择是否改变不能比较 A/B 字母。SemIf 的选项翻转与 BF16 shared-vs-fresh 翻转是两个不同实验。
调用频率 / 延迟尝试数、完成数、采用数分别计数；p50/p95 + 模型/排队/网络分解控制循环 10 Hz ≠ Jev 10 Hz；80 调用 / 65 s ≈ 1.23 Hz。仿真暂停等待、剪去 API 等待的视频不证明实时性。
费用实际计费用量 / 回合，包含两层模型、重试、失败和拒绝有的作者用官方单价估算；单次成功录像与含失败的完整 campaign 不能同分母比较。

官方 Jev SDK 的测试，为什么也不能当作模型质量测试

固定 SDK f078f1e208a0d885154dc758344ae4fce77ac168 的 test_integration.py 给“重复扣费”state 同时问 billing Noul、tone Choice、urgency Score，主要检查模型名、用量、合法范围、候选集合、legend 与概率和。它没有断言该样本的语义 gold label，更没有机器人成功条件。questions.py 验证输入契约；SDK 开源不等于 Jev 内部训练实现公开。
